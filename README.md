# BIM Reference-Data Benchmark Pipeline

A terminal-first pipeline that converts IFC building models into a
queryable DuckDB benchmark database for cross-project analysis.

## What it does

1. Ingests IFC files (IFC2X3 and IFC4 supported)
2. Converts each model to DuckDB with full schema and property sets
3. Normalises element types across IFC versions
   (e.g. `IfcWallStandardCase` and `IfcWall` both map to `element_type = 'Wall'`)
4. Loads results into a shared benchmark database

## Stack

- **ifc2duckdb** — IFC to DuckDB converter (IfcOpenShell-based)
- **DuckDB** — embedded analytical database
- **SQL** — all transformations in version-controlled scripts under `sql/`

## Schema

### dim_project

| column | type | description |
| --- | --- | --- |
| project_id | VARCHAR | unique project identifier |
| name | VARCHAR | human-readable name |
| ifc_schema | VARCHAR | IFC2X3 / IFC4 / IFC4X3 |
| typology | VARCHAR | Residential / Commercial / etc. |
| gfa_m2 | DOUBLE | gross floor area |
| location | VARCHAR | site location |
| year | INTEGER | project year |

### fact_element_qty

| column | type | description |
| --- | --- | --- |
| project_id | VARCHAR | FK to dim_project |
| ifc_class | VARCHAR | source IFC class |
| element_type | VARCHAR | normalised type (enables cross-version comparison) |
| quantity | BIGINT | count or measure |
| unit | VARCHAR | count / m2 / m3 / m |
| storey | VARCHAR | storey identifier if applicable |

## Reproduce

    ./setup.sh

Downloads the sample IFC, converts it, builds the schema, loads the
benchmark tables, and prints verification output.

## Design notes

- **Normalisation is the point.** Without `element_type`, an IFC2X3
  project (`IfcWallStandardCase`) and an IFC4 project (`IfcWall`)
  would be incomparable. The `element_type` column exists solely to
  make cross-project benchmarks valid.
- **Scripts over binaries.** `.duckdb` files are regenerated by
  `setup.sh`. Anyone cloning the repo can reproduce the numbers exactly.
- **Reference layer, not project layer.** The schema is designed to
  accumulate data across projects over years.
